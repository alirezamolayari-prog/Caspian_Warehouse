# راه‌اندازی شبکه‌ای (چندکاربره)

در حالت شبکه‌ای، یک رایانه «سرور» پایگاه داده MariaDB را نگه می‌دارد و بقیه رایانه‌ها به آن وصل می‌شوند.

## روی رایانه سرور

1. **نصب برنامه و پایگاه داده:** نصب‌کننده «انبار کاسپین» را اجرا کنید و گزینه نصب پایگاه داده (MariaDB) را فعال بگذارید؛ رمز مدیر پایگاه داده را یادداشت کنید. (یا MariaDB را جداگانه از mariadb.org نصب کنید و گزینه «Enable access from remote machines for root» را فعال نکنید.)
2. **اجازه اتصال از شبکه:** در فایل `my.ini` (پوشه data نصب MariaDB) در بخش `[mysqld]`:
   ```ini
   bind-address = 0.0.0.0
   ```
   سپس سرویس MariaDB را از Services ویندوز راه‌اندازی مجدد کنید.
3. **فایروال:** پورت TCP ‏3306 را فقط برای شبکه داخلی باز کنید:
   ```powershell
   New-NetFirewallRule -DisplayName "MariaDB (LAN)" -Direction Inbound -Protocol TCP -LocalPort 3306 -RemoteAddress LocalSubnet -Action Allow
   ```
4. **حساب شبکه برای سایر رایانه‌ها:** نصب‌کننده، کاربر برنامه را فقط برای خود سرور می‌سازد. برای سایر رایانه‌ها یک بار دستور زیر را در PowerShell روی سرور اجرا کنید (`YOUR-LAN-PASSWORD` را با یک رمز قوی لاتین جایگزین و یادداشت کنید؛ رمز `root` را هم می‌پرسد):
   ```powershell
   & "C:\Program Files\MariaDB 11.8\bin\mariadb.exe" -u root -p -e "CREATE USER 'caspian'@'%' IDENTIFIED BY 'YOUR-LAN-PASSWORD'; GRANT ALL PRIVILEGES ON caspian.* TO 'caspian'@'%';"
   ```
   (اگر MariaDB را جداگانه نصب کرده‌اید و هنوز برنامه را روی سرور اجرا نکرده‌اید، می‌توانید به‌جای این دستور در اولین اجرا گزینه «نصب جدید: ساخت کاربر اختصاصی برنامه» را همراه با «اجازه اتصال سایر رایانه‌های شبکه» بزنید.)
5. نشانی IP سرور را پیدا کنید (`ipconfig`) و بهتر است آن را در مودم/روتر ثابت (Reserved) کنید.

## روی هر رایانه کاربر

1. برنامه را نصب کنید و گزینه نصب پایگاه داده را **غیرفعال** کنید؛ سپس برنامه را اجرا کنید.
2. «سرور شبکه» را انتخاب کنید و نشانی IP سرور، نام پایگاه داده (`caspian`)، کاربر (`caspian`) و «رمز شبکه» مرحله ۴ را وارد کنید. رمز در Windows Credential Manager همین رایانه ذخیره می‌شود.

## نکات

- **هم‌زمانی:** اگر دو نفر هم‌زمان یک کالا یا سند را ویرایش کنند، دومی پیام «این رکورد در این فاصله تغییر کرده» می‌گیرد و باید دوباره باز کند؛ هیچ تغییری بی‌صدا بازنویسی نمی‌شود. موجودی هنگام ثبت اسناد قفل می‌شود و شماره اسناد تکراری نمی‌شود.
- **پشتیبان‌گیری** را روی رایانه سرور زمان‌بندی کنید (کارهای زمان‌بندی‌شده فقط روی رایانه‌ای اجرا می‌شوند که در آن تأیید شده‌اند). نسخه‌ها را هر از گاهی روی حافظه جداگانه کپی کنید.
- **کلیدهای هوش مصنوعی، توکن تلگرام و رمز پشتیبان** برای هر رایانه جدا ذخیره می‌شوند؛ تنظیمات سرویس‌ها و گیرندگان بین همه مشترک است.
- **دسترسی ابزارهای بیرونی (MCP):** از تنظیمات ← هوش مصنوعی «ساخت کاربر فقط‌خواندنی» را بزنید تا ابزارهایی مثل Claude Desktop فقط بتوانند اطلاعات را بخوانند.
